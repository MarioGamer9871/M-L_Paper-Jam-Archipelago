SETUP INSTRUCTIONS:
1. Download "mlpj.apworld" and install it to archipelago
2. Export a yaml using the Options Creator in Archipelago, and place it in the players folder
3. Generate a game
4. Open Bizhawk and any version of Mario & Luigi: Paper Jam and start a new save file
5. Open "connector_bizhawk_generic.lua" found in "Archipelago/data/lua"
6. Open the Archipelago Bizhawk Client and connect to a slot
